EVERLEAF READING CO. — STOREFRONT STARTER
1) Upload the contents of this folder to a new GitHub repository named everleaf-reading-store.
2) Connect that repository to Cloudflare Pages. Framework preset: None. Build command: leave blank. Build output directory: / (root).
3) The page previews are genuine page renders from the V4 US Letter PDF.
4) Before launch, create the Gumroad product and replace PASTE_GUMROAD_PRODUCT_URL_HERE in script.js with the real product URL.
5) Product delivery PDFs are in /product-files. Upload both to Gumroad as digital product files.
6) Do not publish the product-files folder as a public download from the storefront; it is included here for convenience and should be uploaded to Gumroad only.
Notes: pricing, policies, checkout, domain, and live deployment are not configured yet. Fonts load from Google Fonts with Georgia/Arial fallbacks.
